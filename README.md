# Управление светодиодом с помощью кнопки (Arduino)

## Описание
Простой проект на C++ для Arduino, демонстрирующий управление светодиодом через тактовую кнопку. При нажатии — светодиод горит, при отпускании — гаснет.

## Компоненты
- Arduino Uno (или Nano)
- Светодиод
- Резистор 220 Ом
- Тактовая кнопка

## Схема подключения
- Светодиод: анод → пин 13, катод → GND через резистор 220 Ом
- Кнопка: один контакт → пин 2, другой → GND

## Что демонстрирует проект
- Работа с цифровыми входами/выходами (digitalRead, digitalWrite)
- Условный оператор if-else
- Чтение сигнала с кнопки
